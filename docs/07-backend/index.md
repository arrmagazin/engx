Backend engineering is the server side of a system: the process that takes a request, applies the rules, and reads or writes the data. The concepts — databases, caching, messaging, client-server communication — are framework-neutral and live in [System Design](../03-system-design/index.md). This chapter is the exception to the book's no-framework rule: each guide distills one mainstream server stack from its official documentation, at the version named at its top.

- Every guide follows the same shape: a facts table, setup, the programming model, web, data, security, and testing.
- Versions move. Each guide states the release it was checked against; trust the linked official documentation over this book when they disagree.
