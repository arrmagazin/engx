# Shift Left

**Shift left** means moving testing, security, and other quality work earlier in the delivery cycle, toward the left-hand end of a timeline drawn from requirements to release. The argument is cost: a defect found while the code is being written is cheaper to fix than the same defect found in production, where diagnosis, coordination, and rework are added on top of it.
